# foxhackerzdevs.github.io

Official website for Fox Hackerz — focused on cybersecurity, automation, and developer tooling.

## About

This repository contains the source files for the Fox Hackerz personal website hosted as a GitHub Pages site. It showcases cybersecurity content, automation projects, and developer resources.

## Contents

- `index.html` — main website page
- `LICENSE` — repository license
- `README.md` — project overview and instructions

## Deployment

This repository is intended to be served via GitHub Pages. To publish changes:

1. Commit updates to the repository.
2. Push to the default branch.
3. Verify GitHub Pages deployment in repository settings.
